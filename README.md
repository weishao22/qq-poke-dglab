# QQ 戳一戳 × 郊狼联动

> AI辅助开发项目

基于 Node.js 的自动化程序：当 QQ 群内**特定的人被戳一戳**时，联动 **DG-LAB 郊狼脉冲主机** 发出电击脉冲，支持**多档位强度调节**，全部设置可通过**网页控制台**修改。

```
QQ 群戳一戳 ──► OneBot V11 (NapCat) ──► 本程序(WS 客户端) ──┐
                                                        ├─ 内置 DG-LAB V3 WS 服务器 ◄── DG-LAB App(被控端) ── 郊狼主机
                      网页控制台(配置/档位/测试) ◄────────┘
```

## 架构说明

- **机器人侧（客户端 WS）**：本程序以 **OneBot V11 正向 WebSocket 客户端**身份连接机器人框架
  （如 NapCat 的 `/` 通用端点），接收事件、发送 API（协议参考仓库内 `onebot-11-master/communication/ws.md`）。
- **郊狼侧（服务器 WS）**：本程序**内置 DG-LAB Socket V3 WebSocket 服务器**（协议参考仓库内
  `dglab-websocket-server-main/v3-server.ts` 与 `郊狼网页控制台/server.js`）。本程序同时充当
  协议中的**控制端**，DG-LAB App 作为**被控端**扫码直连本程序，无需任何外部中继服务。
- **协议**：与 App 之间使用官方 Socket V3 协议消息：`strength-通道+2+强度`、`clear-通道`、
  `pulse-A:["16位十六进制帧",...]`；波形帧按郊狼 V3 蓝牙协议（`coyote/v3/README.md`）生成，
  每帧 8 字节 = 4×波形频率 + 4×波形强度，代表 100ms 输出。

## 工作原理

1. 本程序连接 OneBot，收到 `notice_type=notify, sub_type=poke`（群内戳一戳）事件后比对被戳人 `target_id`：
   - 可配置**戳机器人自己时触发**（`matchSelf`）；
   - 或指定目标 QQ 列表（`targetQq`），只有这些号码被戳才触发；
   - 可限定群号、限定发起人白名单、设置冷却时间。
2. 触发后按**当前档位**（强度 / 频率 / 波形强度 / 时长 / 通道）直接向已配对的 App 下发
   `clear` + `strength` + `pulse` 指令，App 通过蓝牙驱动郊狼主机输出。
3. 网页控制台可实时修改所有配置、切换档位、手动测试电击、紧急停止、查看日志；群内也可用命令切换档位。

## 环境要求

- Node.js 18+（开发环境为 v24）
- 任一 OneBot V11 实现（推荐 [NapCat](https://napcat.napneko.icu/)、LLOneBot、go-cqhttp），开启**正向 WebSocket**，例如监听 `0.0.0.0:6700`（参考仓库内 `bot（java-paperQQ消息互通机器人）/qq-bridge/README.md` 的 OneBot 配置说明）
- 手机上安装 DG-LAB App 并已连接郊狼脉冲主机
- 本机防火墙放行网页控制台端口（App 需要通过局域网连接本程序）

## 安装与启动

```bash
cd QQ戳一戳郊狼联动
npm install
npm start
```

首次启动自动生成 `config.json` 并生成内置控制端 ID（持久化，二维码长期有效）。启动后可访问：

- 本机: http://127.0.0.1:8081
- 局域网: http://<本机IP>:8081

## 首次配对（关键步骤）

1. 启动本程序，打开网页控制台，确认状态栏「内置中继就绪」。
2. 「连接与配对」卡片会显示二维码（地址形如
   `https://www.dungeon-lab.com/app-download.php#DGLAB-SOCKET#ws://<局域网IP>:8081/<控制端ID>`）。
3. 手机 DG-LAB App 内使用「Socket 控制」扫码接入本程序内置中继。
4. 状态栏显示「App 已配对」后，点「测试当前档位」验证设备是否输出。

> 若手机无法连接：确认手机与电脑同一局域网、防火墙放行 8081 端口。App 接入地址默认按**当前页面网址**自动识别
> （`http://` → `ws://`，`https://` → `wss://`）；如需手动指定，可在「连接设置 → App 接入地址（对外地址）」填写
> `ws://你的IP:8081` 或公网 `wss://域名:端口`。
> 若郊狼主机没反应：确认 App 与郊狼已蓝牙连接、通道已接电极、档位强度不为 0，并查看「运行日志」。

## 档位说明

每个档位包含：

| 参数 | 范围 | 说明 |
| ---- | ---- | ---- |
| `strength` | 0-200 | 通道强度（电压高度，官方协议范围 0~200） |
| `freqMs` | 10-1000 | 波形频率（ms，越小越密集，10ms=100Hz） |
| `waveStrength` | 0-100 | 波形强度（脉冲宽度体感，V3 协议范围 0~100） |
| `durationSec` | 1-300 | 输出时长（秒） |
| `channel` | A / B / AB | 输出通道 |
| `customWave` | 文本 | 自定义波形（见下），留空用默认脉冲包络 |

默认内置 5 档，从轻微到强烈。档位模式：

- **固定档位**：每次触发都用「当前档位」；
- **循环递增**：每次触发自动切到下一档，到顶后回到第一档。

### 叠加时长

开启「叠加」（`trigger.stack`，默认开）后：**当前波形尚未结束时**再次触发，不会重新开始，
而是**在当前剩余时长上追加该档位的时长**（例如五档还剩 10 秒时又有人戳，变为 10+5=15 秒）；
波形结束后再次触发则正常重新开始。控制台「连接与配对」卡片会实时显示两个通道的**波形剩余时间**。

### 强度指令重发

开启「强度重发」（`trigger.strengthRetry`，默认开）后，每次电击在发送强度指令 150ms 后
再重发一次相同指令，避免 App 端偶发丢失强度导致输出强度不正确；叠加时若新档位强度不同也会补发强度。

### 自定义波形

网页端每个档位提供「导入 .pulse 波形文件」按钮（支持 **DG-LAB App 官方导出的 `.pulse` 文件**）：
选择文件后自动解析并转为 16 位 hex 帧存入该档位（含禁用小节跳过、固定/渐变频率模式等原样转换），
触发时循环补齐到 `durationSec` 总时长；导入后显示帧数/时长，可点「清除自定义波形」恢复默认包络。

解析逻辑与 `郊狼网页控制台/public/index.html` 的官方格式实现一致，已对 BOM/换行符做兼容处理。

> 底层 `customWave` 字段也支持两种手工格式（供高级/API 使用，网页端不再提供手工输入框）：
> 1. **频率:强度 对**：`100:60, 50:40, 30:20, 100:0` —— 每帧 4 个相同频率 + 4 个相同波形强度；
> 2. **16 位 hex 帧**：`646464643C3C3C3C, 3232323228282828` —— 直接按 V3 协议 4×频率字节 + 4×强度字节编写。
> 格式无效时触发会回退默认包络并记录警告日志。

### 网页端调节

「档位管理」卡片中可增删档位、修改各参数、点击「测试」单独试某一档，
「设为当前」切换默认档位，修改后点「保存全部档位」生效。

### QQ 群内命令调节

| 命令 | 说明 | 权限 |
| ---- | ---- | ---- |
| `/档位` | 查看全部档位与当前档位 | 所有人 |
| `/档位 <编号>` | 切换档位（如 `/档位 3`） | 管理员 |
| `/电` | 立即以当前档位触发 | 管理员 |
| `/电停`（或 `/急停`） | 紧急停止：清除波形、强度归零 | 管理员 |

管理员由 `adminQq` 配置；**留空则群内所有人**都可使用管理命令（默认）。

## 网页控制台功能

- **登录与安全**：首次访问需设置密码（此后登录进入），支持修改密码、退出登录；
  可开启**登录人机验证**（Cap 自托管 CAPTCHA），验证失败/缺失/服务不可达一律拒绝登录；
- **连接与配对**：OneBot 连接状态、App 接入地址与配对状态、配对二维码、冷却剩余、手动测试、重连 OneBot；
- **触发设置**：总开关、戳机器人触发、目标 QQ、限定群、发起人白名单、冷却秒数、戳去重秒数、叠加开关、强度重发开关、档位模式、群内通知文案；
- **连接设置**：OneBot 地址与 token、App 接入地址（对外地址）、波形包频率、管理员 QQ、控制台端口；
- **登录与安全**：人机验证开关与 Cap 配置、会话时长、修改密码；
- **档位管理**：增删改档位、单独测试、切换当前档位；
- **运行日志**：实时查看事件与错误。

> 网页控制台与服务器之间使用 **WebSocket 实时通道**（同端口 `/ws`，需登录会话）：状态
> （连接/配对/触发/冷却）与日志实时推送，也可通过 WS 下发动作；WS 断开时自动回退为轮询。

## 登录与人机验证

### 登录

- 首次打开网页控制台（http://127.0.0.1:8081）会进入「设置密码」页面，设置后即可进入；
- 之后每次访问需输入密码登录，会话默认保持 7 天（可配置），退出登录后需重新登录；
- 连续 5 次登录失败会锁定 1 分钟；
- 密码以 scrypt 加盐哈希存储（`scrypt:<salt>:<hash>`），不会以明文出现在配置文件中，
  网页端回传的配置也不会携带密码哈希（修改密码请用「登录与安全」卡片中的表单）。

### 人机验证（Cap）

登录时可选启用 Cap 自托管 CAPTCHA（标准组件，约 1 秒证明工作量，无图片验证码）：

- 在「登录与安全」卡片勾选「启用登录人机验证」，填写 Cap 站点密钥、服务器地址与密钥后保存；
- **密钥仅保存在服务器端**（`config.json` 的 `security.capSecret`），也可通过环境变量
  `CAP_SECRET_KEY` 提供（优先级更高），浏览器端永远拿不到；
- 每次登录都会在服务器端调用 `POST <Cap服务器>/<站点密钥>/siteverify` 校验令牌：
  缺失令牌、无效令牌、令牌已使用、服务不可达时**一律拒绝登录**（fail-closed）；
- 组件从本地 `node_modules/cap-widget` 静态托管（`/cap-assets/`），无需访问国外 CDN；
  WASM 不可用时组件自动回退纯 JS 求解（速度略慢）；
- 默认站点：`https://cap.qyserver.s.odn.cc`，站点密钥 `242df05265`。

> 安全提示：若 Cap 密钥曾在聊天/公开渠道泄露，请在 Cap 后台轮换密钥，并更新
> `config.json` 或 `CAP_SECRET_KEY`。

## 配置文件参考（config.json）

```jsonc
{
  "onebot": { "wsUrl": "ws://127.0.0.1:6700/", "accessToken": "" },
  "dglab": {
    "controllerId": "",  // 内置控制端 ID，首次启动自动生成并持久化
    "sendsPerSec": 10    // 每秒向 App 发送波形包数（1-10，默认 10 = 每 100ms 一包）
  },
  "trigger": {
    "enabled": true,          // 总开关
    "matchSelf": true,        // 戳机器人自己时触发
    "targetQq": [],           // 被戳的目标 QQ（可多个）
    "groupIds": [],           // 限定群号，空=所有群
    "allowedPokers": [],      // 发起人白名单，空=所有人
    "cooldownSec": 5,         // 触发冷却（秒）
    "pokeDedupSec": 3,        // 同一人戳同一目标的重复事件去重（秒），0=关闭
    "stack": true,            // 叠加：波形未结束时再次触发追加时长，不中断当前波形
    "strengthRetry": true,    // 每次电击 150ms 后重发一次强度指令，防止 App 端强度丢失
    "notifyGroup": true,      // 触发后群内发通知
    "notifyText": "【电击联动】{gear}（通道 {channel} 强度 {strength}，{duration} 秒）",
    "gearMode": "fixed"       // fixed=固定档位 cycle=循环递增
  },
  "gears": [ /* 见档位说明，默认 5 档；每档可含 customWave 自定义波形 */ ],
  "currentGear": 1,
  "adminQq": [],              // 群命令管理员，空=所有人
  "security": {
    "loginPasswordHash": "",  // scrypt:salt:hash，首次设置密码后生成（网页端不回传）
    "sessionHours": 168,      // 登录会话时长（小时）
    "captchaEnabled": false,  // 登录人机验证开关
    "capSiteKey": "242df05265",
    "capServerUrl": "https://cap.qyserver.s.odn.cc",
    "capSecret": ""           // Cap 密钥，也可用环境变量 CAP_SECRET_KEY（优先）
  },
  "web": {
    "host": "0.0.0.0",
    "port": 8081,             // 网页控制台与内置郊狼中继共用端口
    "publicAddr": ""          // App 接入地址的对外基址，留空自动按当前访问网址识别（http→ws，https→wss）
  }
}
```

通知文案占位符：`{gear}` `{strength}` `{channel}` `{duration}` `{freq}` `{user}` `{target}`。

## 安全警告

- 郊狼主机输出的是**真实电击**，请先使用最低档位小强度测试确认设备工作正常；
- 请合理设置冷却时间，避免高频连续触发；
- 若 App 断开，程序会记录日志并在 App 重新扫码接入后自动恢复配对，配对恢复前触发会失败但不会漏电；
- 网页控制台需要密码登录（首次使用设置密码），请使用强密码；公网暴露时建议叠加反向代理鉴权/HTTPS；
- DG-LAB App 的接入通道（Socket V3 协议）不经过网页登录（App 无法携带会话 Cookie），
  其访问控制由「配对」决定：只有携带正确控制端 ID 的 App 才能接入并接收电击指令。
